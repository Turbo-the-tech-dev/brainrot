# Tab Completion Possibilities

When you press **Tab** twice in bash, it displays all possible completions for the current context. This file documents all available completion possibilities.

## Shell Commands

These are executable commands and bash keywords available in your shell:

<!-- Commands will be listed below -->

### Command Categories Explained:

| Category | Description |
|----------|-------------|
| **Built-in commands** | Commands built into bash itself (e.g., `cd`, `echo`, `export`) |
| **Keywords** | Bash scripting keywords (e.g., `if`, `then`, `for`, `while`) |
| **External commands** | Executable programs in your PATH (e.g., `ls`, `grep`, `python`) |
| **Aliases** | Shortcuts you've defined for longer commands |
| **Functions** | Custom bash functions you've created |

### Common Commands:
- `cd` - Change directory
- `ls` - List directory contents
- `cat` - Concatenate and display files
- `grep` - Search text patterns
- `mkdir` - Create directories
- `rm` - Remove files/directories
- `cp` - Copy files
- `mv` - Move/rename files
- `chmod` - Change file permissions
- `ps` - Display running processes
- `kill` - Terminate processes
- `ssh` - Secure shell connection
- `git` - Version control
- `python`/`python3` - Python interpreter
- `node` - Node.js runtime
- `npm` - Node package manager
- `vim`/`nano` - Text editors
- `curl`/`wget` - Download tools
- `man` - Display manual pages
- `help` - Show bash help

|----------|-------------|
| `HOME` | Your home directory path |
| `PATH` | Directories searched for commands |

---

## How Tab Completion Works

1. **Single Tab**: Completes if there's only one match
2. **Double Tab**: Shows all possible matches when ambiguous
3. **Partial + Tab**: Completes up to the common prefix

### Tips:
- Type a few characters first, then press Tab for filtered results
- Use `Tab` after commands like `cd `, `cat `, etc. for context-aware completion
- Press `Ctrl+D` when prompted "Display all possibilities?" to see all options
