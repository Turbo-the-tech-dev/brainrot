# Security Policy

## Supported Versions

The Brainrot repository is in active development. Only the latest version is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.x    | :white_check_mark: |
| < v1.x  | :x:                |

## Reporting a Vulnerability

**Protocol: Sigma-Sentinel**

If you discover a security vulnerability within this repository, do not create a public issue. Public disclosure of vulnerabilities is considered "cringe" and against the Sigma Code.

Please report vulnerabilities through one of the following channels:

1.  **GitHub Private Vulnerability Reporting:** Use the "Report a security vulnerability" button on the repository's "Security" tab.
2.  **Direct Contact:** Mention @Turbo-the-tech-dev in a private context if available, or follow the instructions in the Private Vulnerability Reporting flow.

### What to Include in Your Report

*   A detailed description of the vulnerability.
*   Steps to reproduce the issue (PoC).
*   Potential impact if exploited.
*   Suggested remediation if known.

## Our Commitment

We aim to acknowledge all reports within **48 hours** and provide a resolution or a timeline for a fix within **7 days**.

Thank you for helping us keep the Brainrot ecosystem secure. Stay Sigma. 🛡️
