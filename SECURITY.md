# Security Policy

## Supported Versions

The following versions of this project are currently being supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

Vulnerabilities should be reported via GitHub Private Vulnerability Reporting or directly to @Turbo-the-tech-dev.

We will acknowledge receipt of your vulnerability report within 48 hours and strive to provide a resolution within 30 days.
