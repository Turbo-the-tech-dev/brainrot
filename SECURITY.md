# Security Policy

## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a security vulnerability, please report it to us privately.

**Please do not open a public issue for security vulnerabilities.**

### How to Report

Please send an email to **security@brainrot.sigma** (simulated) with the following information:

- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact of the vulnerability.

We will acknowledge your report as soon as possible and work with you to resolve the issue.

## Supported Versions

Only the latest version of this repository is supported for security updates.

## Disclosure Policy

We follow a responsible disclosure policy. We ask that you give us a reasonable amount of time to fix the issue before making any information public.
