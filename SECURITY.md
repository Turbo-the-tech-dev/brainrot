# Security Policy

## Reporting a Vulnerability

We take the security of our systems seriously. If you find a security vulnerability, please do not disclose it publicly.

Instead, please report it via one of the following methods:

1.  **GitHub Private Vulnerability Reporting**: Use the "Report a vulnerability" button on the Security tab of this repository.
2.  **Direct Contact**: Message @Turbo-the-tech-dev directly with details of the vulnerability.

We will acknowledge your report within 48 hours and provide a timeline for resolution.

Thank you for helping keep Brainrot secure.
